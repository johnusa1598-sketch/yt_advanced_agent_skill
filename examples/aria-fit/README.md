# Aria Fit example

This folder is a worked example, not a live channel export.

- `channel.md` is a filled-in channel profile from a public audit
  on 24 October 2026: 92 subscribers, 33 Shorts, 76,938 total views.
- `videos.json` is a 21-video sample from that audit, not the full
  33-video list. Use it to try `yt-analytics`:
  `python3 skills/yt-analytics/analytics.py examples/aria-fit/videos.json`
  Do not read the sample's subs-per-1000-views as the full channel
  rate, because the sample covers fewer views than the full total.
